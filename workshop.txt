description=[H2]How it works[/H2]
description=[list]
description=[*]A spawn point is somewhere you have been, not somewhere on a list. Walk near one and you remember it
description=[*]Your list is per character and lives in the character record, so it survives a restart
description=[*]A new character wakes up in an off grid arrival room rather than on a kerb, so the first thirty seconds are theirs. Needs PhunInteriors; without it you wake up at the point itself
description=[*]Players can mark places of their own, if the server allows it
description=[*]Every constraint is a sandbox option. Turn any of them off if it is taking away the phun
description=[/list]
description=
description=[H2]For mod authors[/H2]
description=Points are registered, not hard coded. Hook the vanilla OnInitGlobalModData event and call PhunSpawn.registerPoint to add your own. Ids are namespaced so nothing collides, and a point registered late is indexed the moment it arrives, so your load order cannot break ours.
